# Yard Site · 群系选区

[English](README.md) | **简体中文**

建新世界的时候，先选好出生点在哪。

这个 mod 会在「创建世界」界面上加一张图：出生点附近的地形和群系，画成三维沙盘。你在图上点一格，
新世界就围着那一格生成，而不是由游戏自己找地方。确认之后不是加载条，是一小段镜头：沙盘推成透视、
绕着落点转，等附近的区块到齐，沙盘散掉，镜头落到出生点上。

## 怎么用

1. 正常点「创建世界」，这张图会先弹出来。
2. 点一格放标记。想看得更细就双击，或者点「进入区块精读」——那里一格就是一个区块，落点会钉在整区块上。
3. 点「确认并创建」。

改种子会重新画图；直接返回、什么都不选，就是原版建世界。

## 装不装庭院系列的区别

只装这一个：选中的那一格就是出生点。出生点区块生成完之后会按真实高度图再校一次 y，所以那一格上
有树或者积雪也不会被塞在里面。

装了庭院系列（`yardcore` 等）：这一格变成庭院占地，庭院那边负责规划建筑原点、把出生点放进院内，
落成镜头会顺路把建筑画成金色线框。

两边互不依赖，单装、都装都行。

## 用投影文件当选址目标（结构模式）

手上已经有一栋现成的建筑？打开 `structure.enabled`、指一份投影文件，整条流程就换成「把这栋建筑放进世界」：

```toml
[structure]
	enabled = true
	file = "config/yardsite/structures/tower.litematic"
	rotation = "CW90"   # NONE / CW90 / CW180 / CW270
	mirror = "NONE"     # NONE / X / Z / XZ
```

打开之后：

- 选区图上的金框就是这份结构的占地，长宽高从文件里读（旋转/镜像之后的尺寸）；
- 落成动画画的是它的**外壳线**：从地基往屋顶一条条扫过去点亮，不再是几个示意盒子；
- 进世界后由本 mod 把方块铺到选中的位置上。出生点取结构里<b>站得住、离门最近</b>的那一格，
  镜头也是从门那一侧绕进来的；
- 坡地、水边、树下会先整平（地基往下补实、占地范围清空）再铺，所以不会有一半埋在土里。

支持 `.litematic`（Litematica）、`.nbt`（原版结构方块）、`.schem`（WorldEdit / Sponge）。
**不需要装投影 mod**：这三种都只是 gzip 过的 NBT，本 mod 自己读，不依赖 Litematica 或 WorldEdit。

线框是**真的消隐**（隐藏线消除）：先列出这份结构<b>全部</b>折角棱，再按当前机位一条条问
"从相机看过去，第一个碰到的是不是它"——是就画，前面挡着别的东西就不画，挡一半就只画露出来的
那一半。所以：

- 立方体底角那三条棱在实体渲染里看不见，这里也不画；
- 两个盒子错开叠放，下面那个被上面盖住的一段轮廓不画，露出来的照画；
- 镜头绕过去，被墙挡住的线自己消失、露出来的又出现。

**几何细到半格以下**：每个方块按真实形状拆成盒子再出棱，不是"一格一个立方体"。
楼梯是台阶、半砖是半格、活板门是 3/16 格厚的板、玻璃板是中间那片薄片、栅栏是柱子加横杆。
线框画的是这些盒子的棱，遮挡也按盒子算——所以一根半砖只会挡住后面柱子下半格，不会整根吞掉。
十字模型的草、花、藤蔓整格跳过（不画线也不挡视线）。

线分三档，分的是**每条棱在形状里扮演的角色**，不是长短：

- **外轮廓**：凸棱，而且它两侧的朝向此刻一正一背对着相机——就是剪影边。最粗最亮。
  这一档**跟着镜头变**：转过去，旧的轮廓退回结构线，新的轮廓顶上来；
- **结构线**：凸棱但此刻不是剪影（台阶、墙棱、方块外缘在内部的那些）；
- **细节线**：凹进去的拐角（门洞内侧、凹槽底），以及玻璃板、活板门、地毯、牌子这些薄片的边。

按角色分而不是按长短分，好处是同一条连续的边永远同一档，镜头怎么转都不会忽粗忽细；
半砖、楼梯的一级（0.5 格厚）和墙棱一样是凸棱，边缘自然接得上。

另外还有一层**屏幕空间筛选**：投影后不到 3.5 像素的棱不画。远景里半格的窗格、栏杆只有两三个
像素，挤在一起全是噪点；近景细节照旧。这就是"退远了自动简化"。

调朝向不用改文件：`rotation` / `mirror` 会把占地方向、出生点、落成线框和真正铺下去的方块一起转，
楼梯和门的朝向也跟着转（方块状态一起镜像/旋转，不是硬贴）。

选区图上按 **T** 顺时针转 90°、按 **M** 换镜像（不镜像 → X → Z → XZ）。这两个只影响<b>这一次</b>建世界，
不写配置文件——对着地形试到哪一面好看，再把值抄进 toml。

`structure.file` **留空**也没关系：会去 `config/yardsite/structures/` 里按文件名取第一个能读的
（`.litematic` / `.nbt` / `.schem`），所以整合包作者把结构丢进那个目录就能用。
连那个目录里也没有文件时**不投影**，选区图顶上一行提示「未设置结构文件」——
不是报错，是不会悄悄拿一份别的建筑去盖。

和庭院系列一起装时，结构模式优先——两套建筑不会同时盖。

## 群系兼容

地图读的是世界自己用的那份群系源，并且支持 TerraBlender。凡是通过 TerraBlender 注册群系的 mod
（比如 Terralith）都能正确显示。其它群系 mod 没有逐个测过，按同样的原理大部分都没问题；
如果是那种在世界生成之后才往地上放群系的 mod，图上可能只显示基础群系。

## 要求

- Minecraft 1.21.1 / NeoForge 21.1.x / Java 21
- 没有必需前置；投影格式也不需要投影 mod（自己解析）
- Sodium 可选：装了以后，真实地形要等所在区块列真的在画才露出来，不会从沙盘缝里透出来；
  没装也能用，只是接缝处理粗一点
- 庭院系列可选，只影响「庭院占地」那套

## 配置

`config/yardsite-common.toml`：

| 键 | 默认 | 作用 |
|---|---|---|
| `site.spawnSiteSelect` | `true` | 是否弹这张图；关掉就是原版出生点 |
| `site.selectRadius` | `2000` | 图的范围，出生点附近 ±N 格 |
| `site.sampleThreads` | `0` | 采样线程数；0 = CPU 核数的一半 |
| `site.spawnChunkRadius` | `3` | 进世界后保活的出生点区块半径 |
| `site.earlyEntry` | `false` | 先放行登录，剩下的区块进世界后再生成 |
| `site.revealAnim` | `true` | 落成镜头；关掉就用原版加载界面 |
| `site.revealSurface` | `true` | 落成动画画「面」而不是「线」（结构模式下就是一栋小模型，装饰都在） |
| `site.revealSurfaceScan` | `true` | 金线先自下而上长出来（C），停 2 秒，再让面自下而上把线框填实（D）；关掉 = 整栋一次出现 |
| `site.revealLineWidth` | `1.5` | 落成线框的线宽（界面像素，和远近无关）；`revealSurface=false` 时才有用 |
| `site.revealLineGlow` | `true` | 线框外面那层很淡的晕；性能紧张可以关 |
| `structure.enabled` | `false` | 用一份投影文件当选址目标（见上一节） |
| `structure.file` | `""` | 投影文件路径，相对游戏目录；支持 .litematic / .nbt / .schem。留空 = 用 `config/yardsite/structures/` 里第一个 |
| `structure.rotation` | `NONE` | 落地时顺时针转多少：NONE / CW90 / CW180 / CW270 |
| `structure.mirror` | `NONE` | 先镜像再旋转：NONE / X / Z / XZ |
| `structure.offsetX/Y/Z` | `0` | 结构整体挪几格（调对位用） |
| `structure.place` | `true` | `false` = 只画线框、不铺方块 |
| `structure.flatten` | `true` | 铺之前把占地范围整平 |
| `structure.maxVoxels` | `4000000` | 允许读进来的体积上限（长×宽×高） |
| `structure.maxLines` | `12000` | 线框最多画多少条线，超了按长度保留长线 |
| `structure.showInfo` | `false` | 选区图左上角那行投影信息（结构名/占地/朝向）要不要显示 |

界面里调过的群系颜色存在 `config/yardsite/site_biome_colors.json`。

## 注意

- 只对单人/局域网建世界生效，专用服务器没有这一步。
- 镜头期间会接管原版建世界的加载界面。如果有别的 mod 也接管这个界面，可能会互相打架，
  可以先把 `site.revealAnim` 关掉对比一下。
- 沙盘是 mod 自己画的，包里不含任何游戏素材，也不含其它 mod 的代码。
- 落成线框的线宽是<b>屏幕像素常数</b>：远处不会细到看不见，推进到门口也不会突然变粗。
- 投影解析有自检脚本：`tools/schematic-check/run.sh`（纯 Java，不用起游戏），
  改过解析或线框算法之后跑一遍。

## 构建

```bash
./gradlew build                  # jar 在 build/libs/yardsite-<版本>.jar
./gradlew runClient              # 开发客户端
```

Sodium 只在编译期用得到，用来编那组可选的剔除钩子。想带上它就把
`sodium-neoforge-0.8.13+mc1.21.1-mod.jar` 放进 `libs/` 再构建；不放也能编过，只是那几个类会被跳过，
mod 照常运行。
