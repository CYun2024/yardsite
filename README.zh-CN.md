# Yard Site · 群系选区

[English](README.md) | **简体中文**

建新世界的时候，先选好出生点在哪。

这个 mod 会在「创建世界」界面上加一张图：出生点附近的地形和群系，画成三维沙盘。你在图上点一格，
新世界就围着那一格生成，而不是由游戏自己找地方。确认之后不是加载条，是一小段镜头：沙盘推成透视、
绕着落点转，等附近的区块到齐，沙盘散掉，镜头落到出生点上。

## 怎么用

1. 正常点「创建世界」，这张图会先弹出来。
2. 点一格放标记。想看得更细就双击，或者点「进入区块精读」——那里一格就是一个区块，落点会钉在整区块上。
3. 点「确认并创建」。

改种子会重新画图；直接返回、什么都不选，就是原版建世界。

## 装不装庭院系列的区别

只装这一个：选中的那一格就是出生点。出生点区块生成完之后会按真实高度图再校一次 y，所以那一格上
有树或者积雪也不会被塞在里面。

装了庭院系列（`yardcore` 等）：这一格变成庭院占地，庭院那边负责规划建筑原点、把出生点放进院内，
落成镜头会顺路把建筑画成金色线框。

两边互不依赖，单装、都装都行。

## 群系兼容

地图读的是世界自己用的那份群系源，并且支持 TerraBlender。凡是通过 TerraBlender 注册群系的 mod
（比如 Terralith）都能正确显示。其它群系 mod 没有逐个测过，按同样的原理大部分都没问题；
如果是那种在世界生成之后才往地上放群系的 mod，图上可能只显示基础群系。

## 要求

- Minecraft 1.21.1 / NeoForge 21.1.x / Java 21
- 没有必需前置
- Sodium 可选：装了以后，真实地形要等所在区块列真的在画才露出来，不会从沙盘缝里透出来；
  没装也能用，只是接缝处理粗一点
- 庭院系列可选，只影响「庭院占地」那套

## 配置

`config/yardsite-common.toml`：

| 键 | 默认 | 作用 |
|---|---|---|
| `site.spawnSiteSelect` | `true` | 是否弹这张图；关掉就是原版出生点 |
| `site.selectRadius` | `2000` | 图的范围，出生点附近 ±N 格 |
| `site.sampleThreads` | `0` | 采样线程数；0 = CPU 核数的一半 |
| `site.spawnChunkRadius` | `3` | 进世界后保活的出生点区块半径 |
| `site.earlyEntry` | `false` | 先放行登录，剩下的区块进世界后再生成 |
| `site.revealAnim` | `true` | 落成镜头；关掉就用原版加载界面 |

界面里调过的群系颜色存在 `config/yardsite/site_biome_colors.json`。

## 注意

- 只对单人/局域网建世界生效，专用服务器没有这一步。
- 镜头期间会接管原版建世界的加载界面。如果有别的 mod 也接管这个界面，可能会互相打架，
  可以先把 `site.revealAnim` 关掉对比一下。
- 沙盘是 mod 自己画的，包里不含任何游戏素材，也不含其它 mod 的代码。

## 构建

```bash
./gradlew build                  # jar 在 build/libs/yardsite-<版本>.jar
./gradlew runClient              # 开发客户端
```

Sodium 只在编译期用得到，用来编那组可选的剔除钩子。想带上它就把
`sodium-neoforge-0.8.13+mc1.21.1-mod.jar` 放进 `libs/` 再构建；不放也能编过，只是那几个类会被跳过，
mod 照常运行。
